## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Document selection

The homepage lets you select, replace, or remove one PDF and displays its filename and size. Selection is local to the browser; no file is uploaded yet. Client-side checks cover the extension, reported content type, filename length, and empty files. PDF content validation and the configured upload size limit remain backend responsibilities when uploads are connected.

## Frontend checks

Use Node.js 24. Run from the `frontend` directory:

```bash
npm run lint
npm test
npm run typecheck
npm run build
```

Component tests use Vitest, React Testing Library, and jsdom. They exercise selection, replacement, removal, and validation feedback.
